## 通用约定（本次复核确认）

- 控件创建模式：`push` 实参后 `call dword ptr [eax+0x20]`，实参从右到左压栈，语义是
  `(this, id, x, y, w, h)`。`call [ecx+8]` 是子控件挂接。
- **带 origin 的图元，(x,y) 是中心点**。`Item/BtGather`、`Item/BtSort`、`Item/BtFull`、
  `Item/BtSmall` 的 origin 都是 (6,6)，`Item/BtCashshop` 是 (46,8)，所以 0x81CF0E 的
  `push 0x1EF / push 0x10A` 是中心 (495,266)，左上角是 (449,258)。origin(0,0) 的
  （`Equip/BtDetail`、`Equip/BtPetEquipShow`、`Item/BtCoin`、`Stat/BtDetail`）才直接当左上角用。
- 窗口基类 0x92C2E8 只创建 id 0x3E8 的边角手柄（2×h，中心在 `[esi+0x590],[esi+0x594]`）；
  关闭按钮由基类按窗口类型挑选节点名（字符串 0x71D / 0x60D / 0x15C9 / 0x878），
  子类构造函数里没有关闭按钮控件。本项目四个面板统一自绘在 (W-19,5) 12×12。
